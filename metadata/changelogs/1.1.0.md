# 1.1.0

## Fixed

- Custom fluid fuels (like lava) now work in every Fluid Generator input path: the GUI fuel slot, right-clicking the machine with a bucket, and fluid or item pipes.
- Custom fluid fuels no longer stop working after the world is saved and reloaded.
- If a future Just Dire Things update breaks compatibility, the game now fails at launch with a clear error instead of custom fuels silently not working.

## Added

- Brazilian Portuguese (pt_br) translation.
