# 1.1.0

## Changed

- Updated to Minecraft 26.1 and NeoForge 26.1. Now requires Just Dire Things 1.6.10 or newer.

## Fixed

- Buckets of custom fluid fuels (like lava) can now be placed in the Fluid Generator's fuel slot in the GUI.
- Custom fluid fuels no longer sneak into other Just Dire Things machines. The Paradox Machine once again only accepts Time Fluid.
- If a future Just Dire Things update breaks compatibility, the game now fails at launch with an error instead of custom fuels silently not working.

## Added

- Brazilian Portuguese (pt_br) translation.
